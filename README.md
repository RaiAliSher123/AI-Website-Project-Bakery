# Sweet Crumbs Bakery – AI Website Project

## Description
Sweet Crumbs is a luxury-style bakery website I created for my Generative AI course at Superior University, Lahore. It is a student demo project, so prices and contact details are samples.

## AI Tools Used
- ChatGPT: prompt engineering (it helped me write a detailed prompt)
- Bolt.new: AI website generation and publishing

## Prompt Given to ChatGPT
I need to create a completely new website for my Generative AI assignment. My topic is a bakery website named Sweet Crumbs Bakery. Please create a detailed, professional prompt that I can paste into Bolt.new. The website should have a luxury and elegant design, be responsive on mobile and desktop, and include bakery photography, product cards with sample prices in PKR, product search, category filters, a working client-side shopping cart, subtle animations, an about/story section, a gallery, and a contact form.

## Features
- Responsive luxury design (ivory, brown and gold theme)
- Hero section with "Freshly Baked Happiness"
- Menu with product search and category filters (Cakes, Pastries, Cookies, Donuts, Bread)
- Product cards with photo, description and sample price in PKR
- Our Story section and photo gallery
- Contact form (demo only) with sample contact details

https://luxury-bakery-websit-5elg.bolt.host

## What I Learned
- A detailed prompt gives a much better website
- ChatGPT can help write better prompts for AI builders like Bolt.new
- AI builds quickly, but I must test and check the result myself
- How to publish a project and document it on GitHub
